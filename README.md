# MVP — Ресторан Первак

> Покращений MVP для **Ресторан Первак** (Ресторан) на основі [Universal Service Template](https://github.com/Mykhailo-Zhuk/universal-service-template).

**Оригінальний сайт:** https://pervak.kiev.ua/
**Дев:** `npm run dev` → http://localhost:3000

## 🎯 Що змінено порівняно з оригіналом

✅ Цифрове QR-меню з 16 стравами
✅ 4 категорії: Закуски, Основні, Напої, Десерти
✅ Реальні ціни та інгредієнти
✅ Онлайн-бронювання столу
✅ Замовлення банкетного залу
✅ Адмін-панель для редагування меню
✅ Темна/світла тема

## 📦 Стек

- **Next.js 14** (App Router) + **TypeScript**
- **Tailwind CSS** + **Framer Motion**
- **Zod** для валідації форм
- **next-intl** для i18n (uk/en/ru)
- Вбудована підтримка **LiqPay / MonoPay** (mock)
- **Telegram Bot webhook** (готовий до підключення)
- QR-коди через `qrcode.react`

## 🚀 Запуск локально

```bash
npm install
npm run dev
# Відкрити http://localhost:3000
```

## 📁 Структура

```
app/
  page.tsx              # Головна лендинг
  book/[serviceId]/     # Онлайн-запис на послугу
  menu/[restaurantId]/  # QR-меню (для ресторанів)
  admin/                # Адмін-панель
    page.tsx            # Дашборд
    bookings/           # Перегляд записів
    menu/               # Управління меню
    settings/           # Налаштування бізнесу
    categories/         # Категорії
    tables/             # Столи
    orders/             # Замовлення
data/
  demo.ts               # Демо-дані бізнесу (послуги/меню)
  settings.ts           # Налаштування (адреса, телефон, години)
```
